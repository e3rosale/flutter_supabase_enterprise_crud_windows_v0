# Database

The app expects a Supabase `users` table.

```sql
create table if not exists public.users (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) <= 120),
  email text not null unique check (char_length(email) <= 320),
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
```

For production, enable Row Level Security and replace the permissive demo
policies with authenticated role-based policies.

```sql
alter table public.users enable row level security;
```

The migration in `supabase/migrations` provides a development baseline.
